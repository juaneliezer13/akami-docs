# 🔤 Directorio de Fuentes Corporativas — Vastago Grotesk

Este directorio almacena la familia tipográfica oficial **Vastago Grotesk** en formato OpenType (`.otf`) suministrada por la marca:

* `VastagoGrotesk-Thin.otf` (Peso 100)
* `VastagoGrotesk-ExtraLight.otf` (Peso 200)
* `VastagoGrotesk-Light.otf` (Peso 300)
* `VastagoGrotesk-Regular.otf` (Peso 400)
* `VastagoGrotesk-Medium.otf` (Peso 500)
* `VastagoGrotesk-SemiBold.otf` (Peso 600)
* `VastagoGrotesk-Bold.otf` (Peso 700)
* `VastagoGrotesk-Heavy.otf` (Peso 800)
* `VastagoGrotesk-Black.otf` (Peso 900)

El frontend (`akamikbeauty`) tiene configuradas las reglas `@font-face` en `src/style.css` y las familias en `tailwind.config.js` para servir estas fuentes de forma nativa en toda la interfaz.
