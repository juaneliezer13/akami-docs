## 📸 Capturas de Referencia del Flujo
1. **Vista Principal (Hero + Filtro Doble):** Selector horizontal de categorías y chips táctiles para tipo de piel.
2. **Selector de Marcas:** Menú desplegable para búsqueda de marcas de culto coreanas.
3. **Modal de Ficha de Producto (Bottom Sheet):** Carrusel de fotos, precio, compatibilidad y botón de pedido con mensaje precargado.
4. **Buscador en Tiempo Real:** Entrada interactiva en cabecera con limpieza rápida y contador de resultados.
